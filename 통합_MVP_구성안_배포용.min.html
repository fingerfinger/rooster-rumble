■ 알 부화 시 1차 기본 스탯(STR/DEX/VIT/MEN/LCK) 초기 생성 분배식

  1. 기본 잠재력(POT) 결정:

  2. 알 등급별 정의된 잠재력 범위 [Min, Max] 내 균등 정수 난수 추출 확정

  3. 1차 기본 5대 스탯 초기 생성 연산식: $$\text{초기 기본 스탯} = \text{Clamp}\left(\text{반올림}\left(\text{잠재력(POT)} \times 0.65\r\r\r\right) + \text{난수}(-3, +3), \;\; 10, \;\; \text{잠재력(POT)}\r\r\r\right)$$

  4. [연산식 설명]: 잠재력(POT)의 65%를 기준 기본 능력치로 설정하고, 5개 스탯(STR, DEX, VIT, MEN, LCK) 각각에 대해 독립적으로 -3 ~ +3의 개체 편차 난수를 합산한 후, 최소 10에서 잠재력 상한선 사이로 고정
  5. [계산 예시 (잠재력 POT 60 알 부화 시)]:
    • 기준 스탯치: $60 \times 0.65 = 39$
    • STR(힘) 난수 +2 발생 시: $39 + 2 = 41\text{ STR}$ 산출
    • DEX(민첩) 난수 -1 발생 시: $39 - 1 = 38\text{ DEX}$ 산출
    • VIT, MEN, LCK도 독립 난수 합산 적용
  6. [계산 예시 (상한 고정)]: 잠재력 POT 30 알에서 연산값 32 산출 시: 잠재력 상한선인 30으로 강제 보정

2.3 닭 캐릭터 10대 상태 머신 및 피로도/부상/회복 규칙

■ 닭 캐릭터 4대 상태 순환 단계

  • 1단계: 탄생 단계 (알 ➔ 닭)
  • 알 보관 (EGG_WAITING): 인벤토리 보관 상태 ➔ 인큐베이터 안치 시 부화 전환
  • 부화 진행 (INCUBATING): 부화 타이머 가동 상태 ➔ 미니게임 완료 시 부화 완료 전환
  • 부화 완료 (HATCHED): 기본 스탯 확정 상태 ➔ 선수 등록 시 기본 대기 전환
  • 2단계: 일상 및 활동 루프
  • 기본 대기 (IDLE): 모든 행동 가능한 기본 상태 (출전·훈련·교배·스파 가능)
  • 훈련 진행 (TRAINING): 능력치 상승 훈련 상태 ➔ 대기시간 만료 시 스탯 상승 후 IDLE 복귀
  • 경기 참전 (IN_MATCH): 시합 출전 상태 ➔ 경기 종료 시 피로도 +15 적재 및 상태 판정
  • 3단계: 피로 및 부상 판정
  • 피로 누적 (FATIGUED): 피로도 70 이상 상태 (출전 시 능력치 -15% 페널티)
  • 부상 발생 (INJURED): 피로도 90 이상 출전 시 30% 확률 발생 (출전/훈련 전면 불가, 유료 스파 전용)
  • 4단계: 회복 및 번식 루프
  • 스파 입욕 (RESTING): 프리미엄 스파 치유 상태 (피로 0 완충, 부상 즉시 완치, 24시간 컨디션 100)
  • 씨닭 지정 (BREEDING_LOCKED): 교배 대기 상태 ➔ 교배 실행 시 2세대 알 생성
  • 교배 휴식 (BREEDING_COOLDOWN): 교배 후 24시간 재교배 잠금 상태 (출전/훈련 정상 가능)

  • [연산식 설명]: 현재 스탯에 상승 스탯을 합산하되, 선수의 타고난 잠재력 상한선을 초과하지 않도록 상한 고정 처리
  • [계산 예시]: 현재 속도 60, 상승 스탯 +6, 잠재력 상한 64 기준: $60 + 6 = 66$이나 상한선(64) 제어로 +4만 상승하여 최종 64 확정 적용

2.5 2세대 교배 시스템 (능력치/잠재력 유전 공식, 패시브/외형 유전 인계, 생애 5회 제약)

  1. 병아리 1차 기본 스탯 유전 수식: $$\text{자식 기본 스탯} = \text{Clamp}\left(\text{반올림}\left(\text{부모A 스탯} \times 0.45 + \text{부모B 스탯} \times 0.45\r\r\r\right) + \text{난수}(-5, +10), \;\; 10, \;\; 100\r\r\r\right)$$
  2. [연산식 설명]: 부모 A, B 스탯의 각 45%를 합산한 90% 계승치에 -5 ~ +10 범위의 유전 변동 난수를 더하고, 최종 값을 10 ~ 100 범위로 고정 산출

  3. [계산 예시]: 부모A 힘 60, 부모B 힘 50, 유전 난수 +4 발생 기준: $(60 \times 0.45 + 50 \times 0.45) + 4 = (27 + 22.5) + 4 = 50 + 4 = 54$ 스탯 확정

  4. 병아리 잠재력 상한 유전 수식: $$\text{자식 잠재력 상한} = \text{반올림}\left(\text{최댓값}\left(\text{부모A 잠재력}, \;\; \text{부모B 잠재력}\r\r\r\right) \times 1.05\r\r\r\right)$$

  5. [연산식 설명]: 부모 중 더 높은 잠재력 수치에 5% 보너스(1.05배)를 곱하여 자식 닭 잠재력 상한선 산출
  6. [계산 예시]: 부모A 잠재력 70, 부모B 잠재력 80 기준: $\text{최댓값}(70, 80) \times 1.05 = 80 \times 1.05 = 84$ 잠재력 상한 확정

■ 베팅 종목 및 정산 산출식 명세 (연승식 Place 미사용)

  1. 단승식 (Win): $$\text{정산금} = \text{베팅 금액} \times \text{단승 배당률}$$
  2. [연산식 설명]: 경주 1위 선수 1마리 적중 시 베팅 금액에 확정 단승 배당률을 곱하여 정산금 지급

  3. [계산 예시]: 베팅 금액 1,000 Gold, 단승 배당률 3.50배 적중 시: $1,000 \times 3.50 = 3,500\text{ Gold}$ 정산 지급

  4. 복승식 (Quinella): $$\text{정산금} = \text{베팅 금액} \times \text{복승 배당률}$$

  5. [연산식 설명]: 순서에 무관하게 1위 및 2위 진입 2마리 조합 적중 시 베팅 금액에 확정 복승 배당률을 곱하여 정산금 지급

  6. [계산 예시]: 베팅 금액 1,000 Gold, 복승 배당률 12.80배 적중 시: $1,000 \times 12.80 = 12,800\text{ Gold}$ 정산 지급

  7. 삼쌍승식 (Trifecta - 추후 업데이트 예정): $$\text{정산금} = \text{베팅 금액} \times \text{삼쌍승 배당률}$$

  8. [연산식 설명]: 1위, 2위, 3위 도착 순위를 정확히 일치시켜 적중 시 베팅 금액에 확정 삼쌍승 배당률을 곱하여 정산금 지급
  9. [계산 예시]: 베팅 금액 500 Gold, 삼쌍승 배당률 85.00배 적중 시: $500 \times 85.00 = 42,500\text{ Gold}$ 정산 지급

■ 동적 배당률 및 수수료 보정 수식

  1. 기본 배당률 산출 공식: $$\text{기본 배당률} = \frac{\text{총 베팅 풀} \times (1 - \text{수수료율})}{\text{해당 선수 베팅금}}$$
  2. [연산식 설명]: 전체 베팅 금액(총 베팅 풀)에서 플랫폼 수수료(10%)를 제외한 순수 환급 풀을 해당 대상의 총 베팅금으로 나누어 기본 배당률 산출

  3. [계산 예시]: 총 베팅 풀 10,000 Gold, 수수료율 10%(0.10), 1번 선수 베팅금 2,000 Gold 기준: $\frac{10,000 \times (1 - 0.10)}{2,000} = \frac{9,000}{2,000} = 4.50\text{배}$ 산출 적용

  4. 최종 배당률 보정 (Clamp) 공식: $$\text{최종 배당률} = \text{Clamp}\left(\text{기본 배당률}, \;\; 1.01, \;\; 99.00\r\r\r\right)$$

  5. [연산식 설명]: 산출된 기본 배당률을 최소 1.01배 ~ 최대 99.00배 범위로 제한 고정 (원금 미만 손실 방지 및 비정상 고배당 리스크 제어)

  6. [계산 예시]:

    • 집중 베팅으로 기본 배당률 0.95배 산출 시: 최소 하한선 1.01배 강제 보정
    • 소액 분산 베팅으로 기본 배당률 150.00배 산출 시: 최대 상한선 99.00배 강제 보정

  8. [연산식 설명]: 총 베팅 풀 대상 10% (0.10) 정액 차감 적용

■ 서버 경주 시간 및 순위 산출 연산식 명세

  1. 스타일별 가중 능력치 연산: $$\text{가중 능력치} = \sum \left(\text{최종 능력치} \times \text{스타일별 가중치}\r\r\r\right)$$
  2. [연산식 설명]: 주행 스타일별 핵심 스탯 가중치(%)를 각 능력치에 곱한 후 전수 합산하여 단일 종합 가중 스탯 산출

  3. [계산 예시 (도주 스타일)]: 도주 스타일(출발 40%, 속도 40%, 지구력 20%) 기준: $\text{가중 능력치} = (\text{출발} \times 0.4) + (\text{속도} \times 0.4) + (\text{지구력} \times 0.2)$ 산출 적용

  4. 기본 경주 시간 산출 공식: $$\text{기본 경주 시간} = 20.0\text{초} - \left(\left(\text{가중 능력치} - 60\r\r\r\right) \times 0.05\text{초}\r\r\r\right)$$

  5. [연산식 설명]: 기준 스탯 60점 기준 기본 완주 시간 20.0초 설정 (가중 능력치 1점 상승 시 완주 시간 0.05초 단축, 1점 하락 시 0.05초 지연 적용)

  6. [계산 예시]: 가중 능력치 80점 보유 선수: 기준(60점) 대비 +20점이므로 $20.0 - (20 \times 0.05) = 19.0\text{초}$ 기본 완주 시간 산출

  7. 레이스 무작위 보정: raceSeed 기반 고정 난수로 -3 ~ +3 정수 보정치 적용

  8. [연산식 설명]: 서버 발급 경기 시드값(raceSeed) 기준 각 스탯에 -3 ~ +3 정수 난수 합산 보정 (동일 시드 및 선수 조합 시 100% 동일 결과 재현)

  9. [시드 키 구조]: raceSeed + ":stat:" + chickenId + ":" + statKey 해시 기반 독립 정수 추출

  10. 최종 도착 시간 산출 연산: $$\text{최종 경주 시간} = \text{Clamp}\left(\frac{\lfloor(\text{기본 경주 시간} + \text{시간 난수}) \times 1000\rfloor}{1000}, \;\; 16.000\text{초}, \;\; 24.000\text{초}\r\r\r\right)$$

  11. [연산식 설명]:

    • ① 미세 시간 난수 합산: 기본 경주 시간에 당일 경기 미세 오차(시간 난수) 합산
    • ② 1/1000초(ms) 단위 절사: 소수점 셋째 자리(1ms 단위) 이하 버림(Math.floor) 처리 후 실제 레이스 기록(예: 18.452초) 확정
    • ③ 안전 한계값 고정(Clamp): 스탯/난수 극단값 발생 시에도 최종 시간을 최소 16.000초 ~ 최대 24.000초 범위로 고정하여 비정상 기록 방지

  12. 동점 처리 규칙 (Tie-breaking): 동일 ms 발생 시 raceSeed 기반 난수(0.000001 ~ 0.999999)를 결합하여 단일 1위 확정

  13. [연산식 설명]: 1/1000초(ms) 단위까지 동일 기록(예: 둘 다 18.234초) 발생 시, 고유 시드 난수를 추가 결합하여 단일 1위 확정 처리

5.1.4.2 Derby Race (경주 2차 스탯) 산출 공식

  • [연산식 설명]: 1차 기본 피지컬 스탯(STR, DEX, VIT, MEN, LCK, POT)에 가중 계수를 곱하여 합산한 후 반올림하고, 주행 스타일에 따른 고유 보정값(Bias §5.2.4.4)을 가산하여 2차 경주 스탯 산출

  • 속도 (Speed): $$\text{속도} = \text{반올림}\left(\text{민첩(DEX)} \times 0.5 + \text{힘(STR)} \times 0.3 + \text{잠재력(POT)} \times 0.2\r\r\r\right) + \text{속도 스타일 보정}$$

  • [계산 예시 (도주 스타일, Speed_Bias +3)]: DEX 60, STR 50, POT 70 기준: $\text{반올림}(60 \times 0.5 + 50 \times 0.3 + 70 \times 0.2) + 3 = \text{반올림}(30 + 15 + 14) + 3 = 59 + 3 = 62\text{ 속도}$ 산출

  • 출발 (Start): $$\text{출발} = \text{반올림}\left(\text{민첩(DEX)} \times 0.7 + \text{행운(LCK)} \times 0.2 + \text{잠재력(POT)} \times 0.1\r\r\r\right) + \text{출발 스타일 보정}$$

  • [계산 예시 (도주 스타일, Start_Bias +8)]: DEX 60, LCK 40, POT 70 기준: $\text{반올림}(60 \times 0.7 + 40 \times 0.2 + 70 \times 0.1) + 8 = \text{반올림}(42 + 8 + 7) + 8 = 57 + 8 = 65\text{ 출발}$ 산출

  • 지구력 (Stamina): $$\text{지구력} = \text{반올림}\left(\text{활력(VIT)} \times 0.6 + \text{정신력(MEN)} \times 0.2 + \text{잠재력(POT)} \times 0.2\r\r\r\right) + \text{지구력 스타일 보정}$$

  • [계산 예시 (추입 스타일, Stamina_Bias +4)]: VIT 70, MEN 50, POT 60 기준: $\text{반올림}(70 \times 0.6 + 50 \times 0.2 + 60 \times 0.2) + 4 = \text{반올림}(42 + 10 + 12) + 4 = 64 + 4 = 68\text{ 지구력}$ 산출

  • 집중력 (Focus): $$\text{집중력} = \text{반올림}\left(\text{정신력(MEN)} \times 0.5 + \text{민첩(DEX)} \times 0.3 + \text{잠재력(POT)} \times 0.2\r\r\r\right) + \text{집중력 스타일 보정}$$

  • [계산 예시 (자재 스타일, Focus_Bias +4)]: MEN 60, DEX 50, POT 60 기준: $\text{반올림}(60 \times 0.5 + 50 \times 0.3 + 60 \times 0.2) + 4 = \text{반올림}(30 + 15 + 12) + 4 = 57 + 4 = 61\text{ 집중력}$ 산출

  • 기술력 (TEC): $$\text{기술력} = \text{반올림}\left(\text{민첩(DEX)} \times 0.4 + \text{정신력(MEN)} \times 0.3 + \text{잠재력(POT)} \times 0.3\r\r\r\right) + \text{기술력 스타일 보정}$$

  • [계산 예시 (테크니션 스타일, TEC_Bias +8)]: DEX 70, MEN 60, POT 60 기준: $\text{반올림}(70 \times 0.4 + 60 \times 0.3 + 60 \times 0.3) + 8 = \text{반올림}(28 + 18 + 18) + 8 = 64 + 8 = 72\text{ TEC}$ 산출

  • 근성 (GRT): $$\text{근성} = \text{반올림}\left(\text{정신력(MEN)} \times 0.6 + \text{활력(VIT)} \times 0.2 + \text{잠재력(POT)} \times 0.2\r\r\r\right) + \text{근성 스타일 보정}$$

  • [계산 예시 (인파이터 스타일, GRT_Bias +0)]: MEN 70, VIT 60, POT 60 기준: $\text{반올림}(70 \times 0.6 + 60 \times 0.2 + 60 \times 0.2) + 0 = \text{반올림}(42 + 12 + 12) + 0 = 66\text{ GRT}$ 산출
