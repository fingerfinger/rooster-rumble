# HTML 기획/명세서 문서 표준 작성 및 배포 가이드

본 가이드는 기획서 및 명세서를 독립 실행형 인터랙티브 HTML 문서로 구축하고, 배포용 압축 파일로 패키징할 때 적용하는 표준 명세이다.

---

## 1. 핵심 작성 원칙

1. **개조식 문체 철저 준수**:
   - `~함.`, `~임.`, `~한다.` 일체 배제, 순수 명사형으로 간결하게 종결.
2. **자화자찬/메타 수식어 배제**:
   - `초정밀`, `원천 방어`, `완벽한` 등 과장된 수식어 일체 금지.
   - 문서 제목 하단의 메타 뱃지(예: `기획 명세서`, `개조식 표준 준수`, `내재화 완비` 등) 제거.
3. **수식 및 연산식 표준화**:
   - KaTeX 렌더링 (`$...$`, `$$...$$`).
   - `[연산식 설명]` 및 구체적 수치를 대입한 `[계산 예시]` 필수 병기.
4. **시각 컴포넌트 우선 (아스키 텍스트 배제)**:
   - 상태 머신: 반응형 대형 SVG 플로우차트 적용.
   - 비교/구조: 2단 카드 그리드 및 데이터베이스 스키마 카드 적용.
   - UI 화면: 상단 HUD 및 5대 탭바가 포함된 모바일 앱 와이어프레임 목업 프레임 적용.

---

## 2. 인터랙티브 기능 표준

1. **좌측 고정 아코디언 목차**:
   - 대분류별 접힘/펼침 토글 (`전체 펼치기`, `전체 접기` 버튼 지원).
   - 목차 실시간 텍스트 검색 필터.
   - 스크롤 위치 감지(Scrollspy) 기반 활성 메뉴 하이라이팅.
2. **다크 / 화이트 테마 전환**:
   - 상단 스위치 원클릭 전환 및 `localStorage`(`rr_theme`) 영구 보존.
3. **마스터 데이터 CSV 내재화 및 내보내기**:
   - 문서 내 raw 문자열 임베딩 (`const MASTER_CSV_DATA = { ... }`).
   - `📥 내보내기`: Excel 한글 깨짐 방지 `UTF-8 with BOM (\uFEFF)` Blob 다운로드.
   - `👁️ 미리보기`: 데이터 테이블 모달 팝업 및 실시간 행 검색.
   - `📋 복사`: 원클릭 클립보드 복사.
   - `📦 6종 전체 CSV 내보내기`: 순차 일괄 다운로드.

---

## 3. 배포용 초경량 압축 버전 (`.min.html`)

- 코드 분석이 불필요한 배포 환경을 위해 공백, 줄바꿈, 주석을 최소화하여 단일 라인 압축.
- 기능(KaTeX, SVG, 테마 전환, 아코디언, CSV 내보내기/미리보기)은 100% 동일하게 유지.
