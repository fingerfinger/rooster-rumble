더비레이스 카메라 제작 도구

1. ZIP을 폴더에 압축 해제합니다.
2. Python 3가 설치된 PC에서 macOS는 start.command, Windows는 start.bat를 실행합니다.
   macOS에서 실행 권한 안내가 나오면 터미널에서 python3 serve.py로 실행할 수 있습니다.
3. 자동으로 열린 시작 화면에서 카메라 에디터 또는 리플레이 뷰어를 선택합니다.
4. 작업 후 에디터의 저장하기로 카메라 JSON을 보관합니다. 새로고침하면 편집 내용이 사라집니다.
5. 실행 창에서 Ctrl+C를 누르면 종료합니다.

브라우저가 열리지 않으면 실행 창에 표시된 주소를 직접 입력하세요.
HTML 파일을 더블클릭해서는 실행할 수 없습니다. Python 3 외 npm 설치·게임 서버·로그인은 필요하지 않습니다.
모델·텍스처·라이브러리는 모두 포함되어 있어 인터넷 연결 없이 동작합니다.
이 ZIP은 생성 시점의 본게임 자산을 담은 사본입니다. 최신 자산을 전달하려면 저장소에서 npm run build:demos를 다시 실행하세요.
두 도구 모두 본게임 카탈로그의 닭 6마리를 표시합니다. 에디터는 고정 6마리, 뷰어는 mock 레이스의 6마리를 표시합니다.
카메라 에디터의 실제 카메라 미리보기는 작은 화면과 메인 화면 모두 16:9로 고정됩니다.
실제 배경·닭 외형·애니메이션을 사용하지만 주행 기록과 우승 레인 시나리오는 제작용 데이터입니다.
