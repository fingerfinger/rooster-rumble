모드 명칭 핵심 재미 주요 플레이 내용

2. 모바일 스토어 서비스 전용 유저 플레이 동선 명세

  • 1단계 (시작 / 첫 경험): 앱 설치 및 로그인 ➔ 보상 수령 (기본 닭 1두 + 1,000골드 + 50사료) ➔ 첫 실행 튜토리얼 (터치 부화, 훈련, 경주 승리, 격투 맛보기) ➔ 메인 로비 진입
  • 2단계 (초기 정착 / 매일 접속): 출석체크 & 광고 2회 시청 (3도장 완료 무료 알 수령) ➔ 알 부화 ➔ 지침 70+ 휴식/온천 케어 ➔ 경주 리그 & 격투 대전 출전
  • 3단계 (숙련 / 심화 플레이): 보석 뽑기 (300 보석 천장) / 거래소 이용 ➔ 5,000골드 2세대 닭 교배 ➔ 7대 전투 기술 5슬롯 장착 & 3연속 콤보 세팅
  • 4단계 (고수 / 마스터): 전설 리그 챔피언 도전 및 영구 칭호 20종 장착 ➔ 알 거래소 매매 진행

3. VIP 라운지 서비스 전용 유저 플레이 동선 명세

  • 1단계 (웹 접속 / 첫 중계 경험): 자체 웹 접속 및 계정 생성 ➔ 신규 가입 보상 10,000 베팅 코인 수령 ➔ 24시간 타임 스케줄 확인 ➔ 실시간 관람 & 경기 시작 전 베팅
  • 2단계 (베팅 정착 / 매일 접속): 경기 진입 전 전적 분석 ➔ 경기 시작 전 베팅 접수 ➔ 경기 중 실시간 베팅 참여 ➔ 수수료(8~10%) 차감 정산금 수령
  • 3단계 (고급 베팅 전략): 실시간 배당 변동 그래프 분석 ➔ 복승식 & 베팅 마감 직전 베팅 수행
  • 4단계 (VIP 토너먼트 마스터): 자체 웹 'VIP 베팅 왕중왕전' 참가 ➔ VIP 라운지 베팅 정산 코인 자산 운용 및 랭킹 관리
