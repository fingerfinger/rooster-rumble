----------------------------------------------------------------------
■ 주요 기획서: ROOSTER RUMBLE_Derby Race_베팅 및 배당 정의_v1.2.9.md (.html)
  - 3. 고정 배당률 및 예상 배당금 산식
    * 3.1 고정 배당률 결정 공식
      - (1) 승리 확률 계산: 출전 6두 피지컬/주행 스탯 기반 승률 연산
      - (2) 고정 배당률 계산 및 범위 제약: Clamp(1.01, 99.00)
      - (3) 시뮬레이션 기반 산출 방식: 표시 배당률 = (1 / 승리확률) * 목표 RTP(0.90)
    * 3.2 예상 배당금 실시간 연산: 베팅 금액 * 적용 배당률 (슬립 및 UI 실시간 표기)
    * 3.3 지급 한도 및 파산 방지: 단일 슬립 최대 지급 한도 10,000 Credit
  - 2.1 단승식 및 복승식의 상세 동작 및 구성 명세 (Win / Quinella 배당 및 적중 요건)

2. 방 생성 및 레이스 시작 (24시간 경기 스케줄러 & 룸 라이프사이클)
----------------------------------------------------------------------
※ 서버에서 24시간 동안 20분 간격(일 72회)으로 자동 스케줄링/생성 및 방 상태를 전이하는 구조

■ 주요 기획서: ROOSTER RUMBLE_Derby Race_MVP_구성안_v3.5.0.md (.html)
  - 3.1 레이스 스케줄러 타임테이블 및 상태 변화 (서버 자동 실행)
    * 일일 스케줄 생성: 매일 00:00:00에 72개 경기 일괄 생성 (경기 ID 규격: R-YYYYMMDD-01 ~ 72)
    * 방 상태 전이: Upcoming(향후 5개 경기 노출) -> Betting Open/Closed(경기 30초 전 마감) -> Live(45초 실시간 레이스) -> Result(종료)
  - 2.1 로비 3단 화면 구조 명세 (중앙 경기 리스트 탭: 방 번호, 타이머, 실제 시작 시각)
  - 2.3 경주 일정 및 출전 로스터 화면 명세

■ 통합 기획서: ROOSTER_RUMBLE_통합_MVP_구성안_v1.2.0.md (.html)
  - 3.1 24시간 경기 스케줄(72회) 및 6두 자동 매칭/게이트 배정 알고리즘
    * 3.1.1 Derby Race 출전 선수 6두 자동 매칭 알고리즘 (1~6번 게이트 자동 배정)
    * 3.1.2 하루치(72회) 경주 24시간 전체 타임 스케줄 명세표 (00:00~23:40)
  - 3.5 경주 결과 연산 공식, 서버 상태 머신 및 클라이언트 시각 보간 명세
    * 서버 레이스 5대 상태 머신 (BettingOpen -> BettingClosed -> RaceResultComputed -> PayoutCommitted -> ResultPublished)
  - 5.4 클라이언트-서버 통신 REST API 17종 (GET /api/v1/derby/schedule, GET /api/v1/derby/matches/{raceId})
